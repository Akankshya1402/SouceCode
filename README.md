# 🚀 Loan Management System — Full Stack Microservices Application

A scalable full-stack loan processing platform built using microservices architecture.  
This system handles loan application, approval workflows, and repayment tracking with secure authentication and real-time processing.

---

## 🧩 Tech Stack

**Backend:** Java, Spring Boot, REST APIs  
**Frontend:** Angular  
**Database:** MongoDB  
**Messaging:** Apache Kafka  
**DevOps:** Docker, Jenkins, SonarQube  

---

## ⚡ Key Features

- 🔐 User Authentication & Authorization  
- 📄 Loan Application & Approval Workflow  
- 💰 Repayment Tracking System  
- 🔄 Asynchronous Communication using Kafka  
- 🧱 Microservices-based Scalable Architecture  
- 📊 REST API-based Service Integration  

---

## 🏗️ System Architecture

- Microservices architecture with independently deployable services  
- REST APIs for inter-service communication  
- Event-driven messaging using Apache Kafka  
- Containerized deployment using Docker
